# Registro de Fauna

Livro digital dos animais que encontramos, organizado por grupo (insetos, peixes, aves, mamíferos...). Cada espécie tem foto, ficha resumida e, nas aves, o canto gravado.

- Site: https://jprabernardes.github.io/registro-de-fauna/
- Dados: `dados/catalogo.json` e `dados/<grupo>/<espécie>/ficha.json`

Privacidade: pessoas não são identificadas, locais aparecem só como região ampla e todas as mídias têm os metadados (GPS etc.) removidos.
